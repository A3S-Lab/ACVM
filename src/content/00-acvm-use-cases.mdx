### 调用量是成本计量，不是付款证明

GEO 购买的不是文章数量，而是独立观测到的引用增量。社会模拟购买的不是一批貌似精确的数字，而是在冻结假设、私有输入和随机过程下得到的可复核群体统计。

这两项服务共享四步：调用方先签名付费结果和验收口径；Agent 在链下执行并留下回执；独立 Validator 检查证据，挑战者可以提交反证；裁决进入终局后，合约才改变状态并付款。调用量仍可用于预算上限和成本核算，但不能单独触发业务结算。

后面的共享账本、共识和确定性虚拟机，只为回答这四步为什么不能被单方改写，以及一笔结果付款什么时候真正不可逆。

### GEO 服务验证的不是写作过程

`GEO Worker` 可以自行选择内容策略和工具，但不能自行决定成绩。验收任务要绑定签名问题集、观测源、采样频率、排除项、基线快照和观察窗口。独立观察节点提交可追溯样本，Validator 计算增量并检查数据口径。

```text file="geo-verification-evidence.txt"
intentRoot + baselineRoot
artifactRoot + publishReceipt
querySetRoot + observationRoot
delta + validatorQuorumCertificate
finalReceiptRoot + settlement
```

链上记录的是规则、证据承诺、裁决和资金状态，不是搜索引擎本身。若样本来源或增量计算遭到挑战，任务停在暂定状态，不能提前付款。

### 可复核不等于预测必然正确

协议能证明实验是否按声明的模型、样本、随机种子和统计管线运行，也能证明公开结果来自通过复核的聚合轨迹。它不能消除模型偏差、分布漂移或错误因果假设，因此输出必须保留置信区间与适用边界。

```text file="simulation-evidence.txt"
policyCommitment + modelManifestRoot
populationSnapshotRoot + vrfProof
trajectoryRoot + aggregationTranscriptRoot
metrics + confidenceIntervals + validatorSignatures
```

ACVM 在这里承担任务状态和结算协议：谁获准运行、什么证据可以验收、哪条反证能触发挑战、什么时候发布结果并支付服务费。
